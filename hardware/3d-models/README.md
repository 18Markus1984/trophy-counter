# 3D models

Printable parts in `.3mf`. The frame and back panel are shared between both
versions; swap only the front panel.

| File | Part |
| ---- | ---- |
| `frame.3mf` | Main frame |
| `backpanel.3mf` | Back panel (friction fit, no fasteners needed) |
| `front-printables.3mf` | Front with Printables logo |
| `front-youtube.3mf` | Front with YouTube play button |

Print the base in a solid, opaque color so the display light only shows through
the number window. Place a sheet of plain paper between front and back panel to
diffuse the light and hide the display's dark segments.
